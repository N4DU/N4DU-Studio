How it works
  1. Open a picture. Drop it anywhere in the window, press Ctrl+V to paste, or use Open.
  2. Edit it. Pick a tool on the left. The line above the picture always says what that tool does. Undo every edit puts the original back.
  3. Choose the export. On the right: whole picture or square for a profile photo, the pixel size, the file type, and an optional weight cap the app will compress down to.
  4. Take it away. Download saves it, Copy puts it on the clipboard for pasting elsewhere, and Replace overwrites an existing file on your disk (desktop version).
  5. Skip step one. In Settings you can add N4DU Studio to the right-click menu for images. After that, right-clicking a picture in your file explorer opens it here already knowing where it lives, so Replace works straight away.
Nothing is uploaded anywhere. Every picture stays on this machine.
Settings
Right-click an image → Edit with N4DU Studio
Adds the entry, with the logo, to the menu you get when you right-click an image file in the file explorer. Opening a picture that way hands N4DU Studio its real location, so Replace can overwrite it where it already lives.
Open in a compact window
Opens N4DU Studio in a small window of its own — no tabs, no address bar — instead of a full browser tab.
Desktop only. A web page cannot change your system. Run main.py (or start.bat) and these switches will set up the right-click entry for you — no registry editing, no administrator rights.
Worth knowing. This works on image files: right-clicking one in the file explorer. Right-clicking a picture inside a browser opens the browser's own menu, which no desktop program can add to — from there, copy the image and press Ctrl+V here instead. On Windows 11 the entry may sit under Show more options. Everything is written to your user account only, and switching it off removes exactly what switching it on created.
