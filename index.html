How it works
  1. Load the files. As many as you like: drop them in, press Ctrl+V, or use Add files. Every one shows up in the list with its size and format. When a file comes from your file explorer, + N more in this folder pulls in the rest of it.
  2. Say what you want out. One format, one size rule and one weight cap for the whole batch. If this browser cannot write the format you picked, it says so instead of producing broken files.
  3. Take them away. Convert & download gives you a single .zip (or separate files, if you prefer). Replace originals overwrites them where they already are — no Downloads folder, no renaming (desktop version).
  4. Skip step one. In Settings, add N4DU Studio to the right-click menu for images. After that: select the files in your file explorer, right-click, and they open here already knowing where they live — so Replace originals works straight away.
  5. Need to touch one up? Editor, in the title bar, opens the selected picture with crop, brush, blur, rotate and colour removal. Come back and the batch uses your edited version.
Nothing is uploaded anywhere. Every picture stays on this machine.

Right-click an image → Edit with N4DU Studio
Adds the entry, with the logo, to the menu you get when you right-click an image file in the file explorer. Select as many as you like — they all land in one window, each knowing where it came from, so Replace originals can overwrite them in place.
Open in a compact window
Opens N4DU Studio in a small window of its own — no tabs, no address bar — instead of a full browser tab.
Desktop only. A web page cannot change your system. Run main.pyw (or start.bat) and these switches will set up the right-click entry for you — no registry editing, no administrator rights.
Undoes the right-click entry and deletes the folder N4DU Studio keeps its settings in. After that, deleting the program's folder leaves nothing behind.
Worth knowing. This works on image files: right-clicking one in the file explorer. Right-clicking a picture inside a browser opens the browser's own menu, which no desktop program can add to — from there, copy the image and press Ctrl+V here instead. On Windows 11 the entry may sit under Show more options. How many of a selection Windows hands over is its decision, not ours, and it varies by version — so however many arrive, the converter offers + N more in this folder to pull in the rest with one click. Everything is written to your user account only, and switching it off removes exactly what switching it on created.
